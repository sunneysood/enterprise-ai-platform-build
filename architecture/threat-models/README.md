# Threat Models

One threat model per project, named `pN-<slug>.md` (for example `p1-api-foundation.md`). Copy [_TEMPLATE.md](https://claude.ai/chat/_TEMPLATE.md) to start.

Each threat model links at least one test that shows a mitigation works, such as an authorization or tenant-isolation test. A threat model with no linked test is a draft.

Review a threat model when the project adds a new entry point, a new data store or a new integration.
